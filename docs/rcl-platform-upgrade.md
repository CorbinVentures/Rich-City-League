# RCL Platform Upgrade

This branch upgrades the public product experience across the splash intro, Performance Lab, profile identity flow, social network, player directory, badges, and fantasy draft room.

## Product changes
- Feature-led cinematic splash intro.
- Modern RCL Performance Lab workspace.
- Player / official / fan identity paths with admin access kept invitation-controlled.
- Password recovery path compatibility at `/profile/reset-password`.
- Basketball-first social feed with stories, filters, reactions, comments and discovery links.
- Active player directory grouped by current teams and alphabetized by last name.
- Richmond × basketball badge catalog with first-class fan badge awards.
- Fantasy draft room with starters, bench, player search and official-stat scoring context.
