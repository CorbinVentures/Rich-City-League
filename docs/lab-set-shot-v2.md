# Set Shot V2 visual contract

Set Shot V1 must read as a basketball shot from every player-facing camera angle, not merely pass skeletal validity checks.

Required sequence:
- controlled two-hand gather
- shooting hand underneath the ball
- vertical shooting-side forearm stack before release
- guide hand stays lateral and peels away
- ball remains anchored to the shooting hand until extension
- release begins only after the arm reaches the set/extension window
- no crossed wrists, collapsed forearms, or detached ball jump

The Lab motion validation now checks baked joint geometry in addition to the generic GLB contract.
